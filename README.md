# Finance Tracker

Локальный сервис для учёта личных финансов: доходы, расходы и аналитика по ним —
в виде графиков, схем и таблиц за выбранный период.

Проект задуман локальным: все данные остаются на машине пользователя, ни один
запрос не уходит во внешнюю среду — так финансовая информация не покидает ваше
окружение.

## Принцип работы

- Все данные хранятся в локальном файле SQLite — отдельный сервер БД не нужен.
- Бэкенд на FastAPI читает и записывает транзакции (поступления и затраты) и
  строит по ним аналитику за указанный пользователем период.
- Схема БД описана моделями SQLAlchemy (`src/core/database/models.py`) и
  управляется миграциями Alembic; файл БД и директории создаются автоматически
  при первом запуске.
- Конфигурация (путь к БД, хост и порт сервера) задаётся в файле `.env`;
  шаблон с ключами — в `.env.example`.

## Стек

- Python 3.12+ и [uv](https://docs.astral.sh/uv/) — управление зависимостями
- FastAPI + Uvicorn — HTTP-бэкенд
- SQLAlchemy — ORM, Alembic — миграции схемы БД
- SQLite — хранилище
- Инструменты разработки: pytest (тесты), ruff (линтер), mypy (тайпчекер)

## Планы

- Учёт доходов и расходов в локальной SQLite-БД
- Аналитика: графики и динамика трат
- Упаковка в десктоп-приложение (ярлык на рабочем столе)
